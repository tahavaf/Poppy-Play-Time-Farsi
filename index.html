راهنمای نصب دوبله

فرقی نداره با کامپیوتر بازی می‌کنی یا گوشی؛ راهنمای مخصوص خودت رو دنبال کن.

WINDOWS / PC

نصب روی کامپیوتر

برای تجربهٔ بازی روی ویندوز

  1. 01فایل اصلی EXE کامپیوتر رو از دکمهٔ پایین دانلود کن.
  2. 02فایل EXE رو اجرا کن و مسیر نصب بازی رو انتخاب کن؛ همون پوشه‌ای که این دو پوشه داخلش هستن:PlaytimeLauncher   /   WindowsNoEditor
  3. 03روی «نصب دوبله» بزن. تمام! حالا بازی رو اجرا کن.
دانلود فایل کامپیوتر ↓
فایل اجرایی ویندوز · EXE
ANDROID / MOBILE

نصب روی گوشی

برای تجربهٔ بازی روی اندروید

  1. 01فایل ZIP نسخهٔ موبایل رو از دکمهٔ پایین دانلود کن.
  2. 02با برنامه‌ای مثل ZArchiver فایل ZIP رو از حالت فشرده خارج کن.
  3. 03فایل نصبی خارج‌شده رو نصب کن. تمام! بازی رو اجرا کن و لذت ببر.
